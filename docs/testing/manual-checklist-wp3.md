# Checklist manuelle WP3 — Templates motion

- [ ] `npm run validate:templates` vert
- [ ] Catalogue : modèles affichés « à fabriquer » si pas de `.mogrt`

- [ ] Paramètres texte / couleur appliqués ou message d’échec + édition manuelle Properties

- [ ] Favoris / récents persistés après rechargement du panneau
